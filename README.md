# Estudos de Java

Repositório com exercícios e projetos de Java que venho praticando durante meus estudos.

## Estrutura

### Fundamentos

- `Vetores/` — exercícios envolvendo arrays
- `Matrizes/` — exercícios envolvendo matrizes
- `Listas/` — exercícios envolvendo List, ArrayList e POO aplicada a coleções
- `Enum/` — estudo sobre enums em Java
- `DateTime/` — estudo sobre a API de Date/Time do Java 8 (LocalDate, LocalDateTime, DateTimeFormatter, etc.)
- `aula-StringBuilder/` — aula/exercícios sobre StringBuilder

### Orientação a Objetos

- `Heranca-e-polimorfismo/` — exercícios de herança e polimorfismo
- `MetodosAbstratos/` — classes e métodos abstratos
- `Interfaces/Locadora-exemplo/` — exemplo de uso de interfaces (locadora)

### Arquivos e exceções

- `ArquivosJava/` — leitura e escrita de arquivos
- `tratamentoDeExcecao/` — tratamento de exceções

### Generics

- `Exercicios/generics/` — classes e métodos genéricos, `Comparable` e tipos limitados (`T extends Comparable<T>`)

### Exercícios diversos

- `Exercicios/` — exercícios variados (conta bancária, POO, ArrayList, Date, generics, etc.)

### Projetos

- `biblioteca-java/` — projeto de estudo (sistema de biblioteca)
- `employee-pay-calculator/` — projeto de cálculo de pagamento de funcionários (Department, Worker, POO)
- `Employee-exercicio-exemplo/` — exercício de exemplo com funcionários

## Tecnologias

- Java
- IntelliJ IDEA
- Git

## Sobre

Este repositório documenta minha evolução no aprendizado de Java, começando por fundamentos (arrays, listas, matrizes, enums, datas) e avançando para Orientação a Objetos (herança, polimorfismo, classes abstratas, interfaces), leitura de arquivos, tratamento de exceções e generics.
